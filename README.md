### 📚 [Multi-Document RAG AI Assistant](https://github.com/pavan-ahire/RAG-Document-Assistent-AI)

*Conversational AI for intelligent PDF question answering using RAG*

- Built a full **Retrieval-Augmented Generation (RAG)** pipeline supporting multi-PDF document Q&A
- Stack: **LangChain · Groq Llama 3.1 · ChromaDB · HuggingFace BGE Embeddings · Streamlit**
- Implemented **MMR semantic retrieval** for diverse, non-redundant context extraction
- Features conversational memory, source citations, hallucination reduction, and PDF chat export
- Modular pipeline architecture: `loader → splitter → embeddings → vectorstore → retriever → LLM → response`

`RAG` `LangChain` `LLM` `ChromaDB` `Vector Search` `Groq` `Streamlit` `GenAI`

---

### 🧠 [NL2SQL — Natural Language to SQL Analytics](https://github.com/pavan-ahire/NL2SQL-Natural-Language-to-SQL-Analysis-) ⭐ 3

*AI system that converts plain English questions into SQL queries and instant visualizations*

- Built **IntelliQuery AI** — an end-to-end NL2SQL platform using **Vanna AI 2.0** with Gemini/Groq/Ollama LLM support
- Stack: **FastAPI · Vanna AI · SQLite · ChromaDB · Plotly · Streamlit**
- Ask questions in plain English → AI generates SQL → validates → executes on DB → auto-generates charts
- Built-in **SQL validation layer** blocking all non-SELECT operations (INSERT, DROP, EXEC, injection) for security
- Trained with 25 Q→SQL pairs; 20-query automated test suite; handles joins, aggregations, CTEs, filters
- Production REST API with Swagger UI, structured JSON responses, and real-time Plotly visualizations

`NL2SQL` `LLM` `Vanna AI` `FastAPI` `Text-to-SQL` `Gemini` `RAG` `Agentic AI`

### 🏥 [Brain Tumor MRI Classification — CNN](https://github.com/pavan-ahire/Brain-Tumor-MRI-Classification-CNN) ⭐ 3

*AI-assisted medical imaging system for brain tumor detection and classification*

- Built a **CNN deep learning classifier** using TensorFlow/Keras trained on thousands of brain MRI images
- Classifies scans into 4 categories: **Glioma · Meningioma · Pituitary Tumor · No Tumor**
- Architecture: `Conv2D → ReLU → MaxPooling → Dropout → Dense (Softmax)` with a **ResNet50 transfer learning** variant
- Deployed as a **Streamlit web app** with real-time predictions, confidence scores, and optional **PDF diagnostic report**
- Full preprocessing pipeline: resize → normalize → batch expand → inference
