## 💡 About Me

I work across the **full data spectrum** — from cleaning a messy spreadsheet and building a Power BI dashboard a manager can act on, to designing an agentic RAG system with access control and tool-calling. I don't box myself into just "AI/ML" — I like the analyst's job of finding the story in the data just as much as I like the engineer's job of shipping the model that acts on it.



- 📊 **Data & Business Analysis** — SQL analytics (joins, CTEs, window functions), Power BI dashboards, Excel reporting, and EDA that turns raw data into a decision a business can make
- 🤖 **Generative AI & Agentic Systems** — RAG pipelines, LLM tool-calling, access control, source-ranking, and confidence scoring — built like a real product, not a demo
- 🧠 **Machine Learning & Deep Learning** — CNNs, ANNs, RNN/LSTMs, and classical ML (KNN, SVM, Naive Bayes, Regression) applied to real classification and prediction problems
- 🛠️ **End-to-end delivery** — from a raw CSV or a stakeholder question, all the way to a deployed FastAPI/Streamlit app or a published Power BI report

## 🚀 Flagship Generative AI Projects

> Agentic, production-style AI applications — the ones I'd actually walk an interviewer through.

### 📦 [ParcelPilot — Customer Support AI Agent](https://github.com/pavan-ahire/ParcelPilot-Customer-Support-Ai)

<img align="right" width="270" src="https://img.shields.io/badge/⭐-Trust%20%26%20Reliability%20Focused-6A0DAD?style=for-the-badge"/>

**A trust-aware, tool-calling support agent for a B2B logistics platform**

Grounds every answer in real policy/contract PDFs and live order data — never from memory. Ranks sources by authority (customer agreement > current policy > deprecated policy), enforces **account-level data isolation in the tool layer** (not the prompt), computes fees/credits with tested Python functions instead of LLM guesses, and gates the one write-action behind an explicit UI confirmation before it ever touches the database.

![Python](https://img.shields.io/badge/Python-3.11+-3776AB?style=flat-square&logo=python&logoColor=white) ![Groq](https://img.shields.io/badge/Groq-Tool%20Calling-F54E00?style=flat-square) ![FAISS](https://img.shields.io/badge/FAISS-Vector%20Search-0467DF?style=flat-square) ![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)

**Highlights:** source-authority ranking · HIGH/MEDIUM/LOW confidence labeling with stated reasons · ownership-checked tools that can't be talked out of an access denial · confirmation-gated escalation with a write function excluded from the model's own tool list

### 📄 [AI Document Assistant — Full-Stack RAG](https://github.com/pavan-ahire/AI-Document-Assistant)

<img align="right" width="300" src="https://opengraph.githubassets.com/1/pavan-ahire/AI-Document-Assistant" alt="AI Document Assistant preview"/>

**Chat with your PDFs/DOCX/TXT — grounded, private, hallucination-free**

Full-stack RAG app with a **FastAPI backend + decoupled Streamlit frontend**, JWT sessions with bcrypt-hashed passwords, and per-document ChromaDB collections. Every answer is grounded strictly in *your* uploaded documents — if it's not in the file, the app tells you instead of making it up.

![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white) ![LangChain](https://img.shields.io/badge/LangChain-1C3C3C?style=flat-square) ![ChromaDB](https://img.shields.io/badge/ChromaDB-4B0082?style=flat-square) ![Groq](https://img.shields.io/badge/Groq%20LLaMA%203.3-F54E00?style=flat-square) ![JWT](https://img.shields.io/badge/JWT%20+%20bcrypt-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)

**Highlights:** secure multi-user auth · timestamped, deletable chat history · zero-cost offline fallback mode when no Groq key is set

### 🏭 [Data Cleaning & Anomaly Detection — ERP Readiness](https://github.com/pavan-ahire/Data-Cleaning-and-Anomaly-Detection-System)

<img align="right" width="300" src="https://opengraph.githubassets.com/1/pavan-ahire/Data-Cleaning-and-Anomaly-Detection-System" alt="Data Cleaning system preview"/>

**Audits, cleans, and scores CSVs for SAP/ERP import readiness — 100% offline, zero APIs**

A zero-dependency pipeline that ingests any CSV, profiles it, detects missing values/duplicates/type mismatches/outliers, flags anomalies with **Isolation Forest**, cleans the data, and computes a weighted **Data Quality Score** and **ERP Readiness Score** — ending in a professional multi-page PDF report, without ever touching the internet.

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white) ![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white) ![pandas](https://img.shields.io/badge/pandas-150458?style=flat-square&logo=pandas&logoColor=white) ![ReportLab](https://img.shields.io/badge/ReportLab-4B8BBE?style=flat-square) ![100% Offline](https://img.shields.io/badge/100%25-Offline-2ea44f?style=flat-square)

**Highlights:** weighted composite scoring rubric (completeness · uniqueness · validity · consistency) · rule-based recommendation engine · validated end-to-end on a synthetic defect-injected dataset

### 🎥 [YouTube Video-to-Article Generator](https://github.com/pavan-ahire/AI-Powered-YouTube-Video-to-Article-Generation-System)

<img align="right" width="300" src="https://opengraph.githubassets.com/1/pavan-ahire/AI-Powered-YouTube-Video-to-Article-Generation-System" alt="YouTube-to-Article preview"/>

**Turns any YouTube video into a structured, publish-ready article**

Extracts transcripts via `youtube-transcript-api` (with a `yt-dlp` fallback for reliability), then uses **Groq LLaMA 3.3** to generate articles with adjustable tone, technical depth, length, and writing style — plus multi-language output and one-click PDF export with reading-time and compression-ratio analytics.
